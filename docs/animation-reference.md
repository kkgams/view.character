# LPC sources and format history

This is the **research inventory**, not the Project's adoption list. See
[[animations|Project animations]] for the current selection and preview table.
Generated by `make database` from `assets/lpc/animations.json`; source layouts
are deliberately kept separate. Use this reference to identify source families
and versions before deciding what to extract and convert into the Project.
**6 legacy/original, 11 extended and 2 community action identities** have verified
representatives; these are not counts of every source-specific variant.

**Reading the tables:** all rows/columns are zero-based and inclusive. Poses are
stored cells, not pixel sizes or playback steps. NWSE means north, west, south,
east. A dash means unknown or not defined—not a default value. Source order is
preserved within each layout; there is no universal alphabetical animation order.

## Identifying an incoming sheet before conversion

“Era” here means a source/layout family and revision, not a reliable date inferred
from its dimensions. These are fingerprints to verify against provenance, not a
heuristic detector that silently assigns a format.

| Source family / example | Verified distinguishing evidence |
| --- | --- |
| Original base templates | Four separate action files; 64px cells; Walk stores idle +8 moving poses; female Spellcast includes two trailing transparent pixel rows. |
| Legacy unified | Six physical action blocks, 832×1344 / 21 rows, in Spellcast→Thrust→Walk→Slash→Shoot→Hurt order. |
| Revised upstream sample | Separate named sheets; Walk8, Idle3, Jump6, Backslash12; smaller head assets and source-specific placement. No canonical combined-sheet order established. |
| Older Expanded sample | The retained female attachment is 832×2944 / 46 rows; appended offsets remain unverified. |
| Modern Universal | Fifteen physical split strips; seventeen preview definitions; 832×3456 / 54-row combined definition. Jump5, shared Backslash13. |
| Optional custom layouts | 64/128/192px cells, borrowed-pose matrices, centered 64px bodies and selection-dependent appended output blocks. |

Before converting:

1. Establish the source project, revision/body model, author chain and allowed
   license; keep original bytes and provenance.
2. Match measured dimensions, padding, frame counts and directions against that
   exact source layout. A 64px grid or familiar filename alone is insufficient.
3. Extract using that source's local or global coordinates. Keep physical poses,
   playback order, timing policy, prealigned heads and cutouts distinct.
4. Explicitly choose which actions/variants belong in the Project and map only
   those into its approved target contract. Do not add actions to the Project
   merely because a source contains them.
5. If target geometry, a missing direction, palette conversion or phase timing
   needs a new decision, record it rather than inventing frames, quantizing art
   or silently treating unlike versions as equivalent.

This page is conversion **evidence**, not an implemented importer or a new target
format specification. The current Project selection remains on [[animations]].

## Historical evidence and compatibility

### Original versus unified

The [original inventory](https://github.com/OpenGameArt/LPC-Style-Guide/blob/5aaa89247480cdf4d9c82c28fdbc5a90a1e9ea0f/source/docs/assets.rst#L9-L34) documents four separate animation
families, and the [original guide](https://github.com/OpenGameArt/LPC-Style-Guide/blob/5aaa89247480cdf4d9c82c28fdbc5a90a1e9ea0f/source/docs/styleguide.rst#L188-L194) specifies back, left,
front, right. The [demo](https://github.com/OpenGameArt/LPC-Style-Guide/blob/5aaa89247480cdf4d9c82c28fdbc5a90a1e9ea0f/source/static/demogame/js/actor_model.js#L552-L571) uses idle column0 and moving columns1–8.
Its movement timing is application behavior, not a normative animation FPS.
Female Spellcast retains two transparent trailing pixel rows: **448×258**, not
an extra animation row. Source files remain unchanged.

The [unified snapshot](https://github.com/makrohn/Universal-LPC-spritesheet/blob/38ba6be1a4721f51b545d58823acdb29955bc02a/body/male/light.png) is verified at commit `38ba6be1a4721f51b545d58823acdb29955bc02a`
(January 2013). This is the earliest standalone male body PNG found in the inspected
path history, not proof of when the layout was invented. The original guide's
Git history is a 2022 import; the current OGA archive also has later credit edits.
Neither establishes that today's exact archive bytes existed in 2012.

### Revised, Expanded and Universal are not one format

The [modern README](https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator/blob/9bf06be193b053db256b2536824af426de046aa2/README.md#L139-L149) distinguishes their layouts, counts,
palettes and head sizes. [Revised placement metadata](https://github.com/ElizaWy/LPC/blob/f07f7f5892e67c932c68f70bb04472f2c64e46bc/Characters/_%20Guides%20%26%20Palettes/HeadPlacement.json)
serializes separate files but does not establish a universal physical order.
The [Expanded author](https://opengameart.org/content/lpc-expanded-sit-run-jump-more) describes preserving the old region and
appending animations; its older 46-row attachment is not the current 54-row
allocation. Attachment/update dates conflict, so chronology is not inferred.

[Durrani / BenCreating's aligned Jump](https://opengameart.org/content/lpc-male-jumping-animation-by-durrani) and the
[2021 expanded Jump](https://opengameart.org/content/lpc-jump-expanded) have **five** poses. The latter describes
a raised fourth pose and optional bent-knee recovery. Later Revised has **six**;
modern Universal has **five**. The exact commit introducing Revised's sixth pose
remains unverified. Revised Backslash has **twelve** poses; modern Universal's
shared source strip has **thirteen**. These versions are represented separately.

### Timing, sequences and custom extraction

[Modern definitions](https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator/blob/9bf06be193b053db256b2536824af426de046aa2/sources/state/constants.ts#L105-L160) specify the exact preview sequences
shown above. Their [player](https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator/blob/9bf06be193b053db256b2536824af426de046aa2/sources/canvas/preview-animation.ts#L182-L199) repeats every preview at
**125ms ticks / 8 FPS**, including Hurt. This is not a mandatory gameplay loop or
an authored one-shot policy. Intrinsic unknown FPS/loop fields remain null.

[Revised guides](https://github.com/ElizaWy/LPC/tree/f07f7f5892e67c932c68f70bb04472f2c64e46bc/Characters/_%20Guides%20%26%20Palettes/Animation%20Guides) contain authored tick/hold instructions.
Project Idle uses 0,1,2,1; known Walk/Run/combat holds are rounded to GIF
centiseconds. `climb`, `combat_1h_halfslash`, `jump`, `legacy_swing` use **illustrative 100ms pose cycles**, not claimed
authored timing. Jump is motion-phase-dependent; Emotes/Sitting are pose sheets.
Head-only Expressions is not a paired body animation. Prealigned heads must not
receive `HeadPlacement.json` offsets a second time.

[Custom definitions](https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator/blob/9bf06be193b053db256b2536824af426de046aa2/sources/custom-animations.ts) and [drawing code](https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator/blob/9bf06be193b053db256b2536824af426de046aa2/sources/canvas/draw-frames.ts#L11-L138)
retain their separate extraction rules. The legacy full-sheet custom row lookup
is one row earlier than modern offsets; split-strip extraction follows its own
local row mapping. Do not substitute one lookup for the other or silently repair
source matrices. Optional custom origins and uncollected item geometry remain
unverified.

The [OGA collection](https://opengameart.org/content/lpc-collection) is a discovery
index, not an author/license/specification authority. Exact first publication
dates, several earliest origins, Expanded appended offsets and uncollected
community layouts remain explicit unknowns. All findings are bounded by the
pinned research snapshot, not a claim to inventory every LPC submission.
